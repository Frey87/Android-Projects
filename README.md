# Android Projects

A collection of Android applications and practice projects developed while learning Android application development.

## Practice Projects

### Login & Register UI
Android application demonstrating login and registration interfaces, navigation between activities, user interaction, and basic UI event handling.

**Technologies:** Java, Android SDK, XML layouts, Activities, Intents.

### Daily Fitness Tracker
Android application that accepts step count, weight, and age data and calculates an estimated number of calories burned.

**Technologies:** Java, Android SDK, XML layouts, Activities, Intents.

### Word Count App
Simple Android application that accepts text input and calculates the number of words entered by the user.

**Technologies:** Java, Android SDK, XML layouts.

## Basic Exercises

### Hello World
Introductory Android application created to practice the basic Android Studio project structure, activities, layouts, and application lifecycle.

**Technologies:** Java, Android SDK, XML.

## Build

Each project includes its own Gradle Wrapper.

For example:

    cd Practice-Projects/DailyFitnessTracker
    ./gradlew assembleDebug

Android SDK must be installed and configured through Android Studio, ANDROID_HOME, or a local local.properties file.

## Notes

Generated build directories, Android Studio configuration files, local SDK paths, and other machine-specific files are excluded from version control.
